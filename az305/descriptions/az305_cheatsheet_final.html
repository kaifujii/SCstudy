11 超頻出の罠 — これだけは落とすな DEADLY
「SQL Server → SQL MI Business Critical をオンライン移行」 → DMSはBC tier非対応 → 正解: MI Link(SQL2022)一択
「Multi-region write + Strong整合性」 → 両立不可 → Sessionにする / 単一書き込みリージョンでStrong
「ACI コンテナの監視」 → Container InsightsはACI非対応 → 正解: Application Insights
「Network Watcher で攻撃をブロック」 → 診断のみ・ブロック不可 → 正解: NSG / Azure Firewall / DDoS Protection
「外部開発者にPIM」 → PIMは社内特権ロール用のみ → 正解: Access Reviews(B2Bユーザー対象)
「異なるVNetのプライベートIPバックエンド + クロスリージョン」 → AGv2 / TM / X-Region LBは不可 → 正解: Front Door Premium(Private Link対応)
「セキュリティの既定値群 + 既存CA」 → 同時利用不可 → 既定値群を無効化 / 既存CAに条件追加で対応
「Logic Apps の SHIR でオンプレSQL」 → SHIRはADF専用 → 正解: 接続ゲートウェイリソース(オンプレデータゲートウェイ)
「Premium ページBLOB / Premium ファイルでADLS Gen2」 → 両方非対応 → 正解: Standard 汎用 v2 + HNS 有効化
「Multi-tenant App Registrationでコンシューマーログイン」 → ビジネスユーザー間用 → 正解: Entra External ID(Azure AD B2C)
