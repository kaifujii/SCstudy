# 情報処理安全確保支援士 午前問題生成スキル

## 概要

このスキルは、情報処理安全確保支援士試験の午前I・午前II形式に準拠した4択問題を生成し、インタラクティブな演習セッションを提供する。

## 問題生成の手順

### Step 1: トピックと難易度の確認

ユーザーがトピックを指定していない場合は、以下の重点領域からランダムに選ぶか、直近の会話で触れたトピックを選択する：

- 暗号技術（RSA、AES、SHA、デジタル署名、PKI）
- 認証・認可（OAuth 2.0、SAML、FIDO2、OpenID Connect）
- ネットワークセキュリティ（TLS/SSL、VPN、ファイアウォール、IDS/IPS）
- Webセキュリティ（XSS、CSRF、SQLインジェクション、SSRF）
- マルウェア・攻撃手法（フィッシング、APT、ランサムウェア）
- セキュリティ管理（リスクアセスメント、ISMS、インシデント対応）
- 法律・規制（不正アクセス禁止法、個人情報保護法、サイバーセキュリティ基本法）

### Step 2: 問題の生成

以下の形式で5問生成する（ユーザーが問題数を指定した場合はそれに従う）：

```
【問X】[問題文]

ア．[選択肢A]
イ．[選択肢B]
ウ．[選択肢C]
エ．[選択肢D]
```

**問題品質の基準：**
- 実際の試験に出題されやすい実践的な内容
- 紛らわしい選択肢を含め、確実な理解が必要な設計
- 単純な暗記ではなく概念の理解を問う問題を優先
- 午前IIはより専門的・詳細な問題（システム監査・セキュリティ技術中心）

### Step 3: 解答待ち

全問提示後、「解答してください」または番号で回答を促す。ユーザーが回答するまで正答は絶対に表示しない。

### Step 4: 採点と解説

ユーザーが解答したら：

1. **採点結果を表示**（例：「3/5問正解」）
2. **各問の解説**を以下の形式で提供：

```
【問X】正答：[ア/イ/ウ/エ]

■ なぜこれが正答か：
[核心的な根拠を2〜3文で]

■ 間違いやすいポイント：
[他の選択肢が誤りである理由、試験での頻出ひっかけ]

■ 関連知識：
[試験で一緒に問われやすい周辺知識]
```

3. 正解率が60%未満の場合、そのトピックの補強学習を提案する

## 注意事項

- 解答前に正答をほのめかさない
- 選択肢の番号（ア〜エ）を一貫して使用する
- 試験本番の時間感覚（午前II：40分で25問 = 1問約96秒）を意識したコメントを適宜入れる
