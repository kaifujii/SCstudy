# 情報処理安全確保支援士 午後問題演習スキル

## 概要

午後試験は長文のシナリオ（企業のセキュリティ事故、システム設計など）に基づく記述式問題。
150分で複数の大問に答える形式。このスキルで本番さながらの演習を提供する。

## 午後問題の特徴

- **企業・組織のシナリオ**：実際に起きうるセキュリティインシデントや設計課題
- **設問の種類**：
  - 穴埋め（適切な語句・技術名を答える）
  - 記述（30〜120字程度で理由・対策を説明）
  - 選択（複数の対策案から最適なものを選び理由を述べる）
- **頻出テーマ**：Webアプリ脆弱性、認証設計、インシデント対応、暗号化設計、ログ分析

## 問題生成の手順

### Step 1: テーマ確認

ユーザーがテーマを指定していない場合、以下から選ぶか提案する：

1. **Webアプリケーションセキュリティ**（SQLi、XSS、CSRF、セッション管理）
2. **認証・アクセス管理**（多要素認証、SSO、特権アクセス管理）
3. **インシデント対応**（マルウェア感染、不正アクセス、情報漏洩対応）
4. **ネットワーク設計**（DMZ、ファイアウォールルール、VPN）
5. **暗号化・PKI**（TLS設定、証明書管理、鍵管理）
6. **セキュリティ監査・ISMS**（リスクアセスメント、内部監査）

### Step 2: シナリオ生成

以下の構成で問題を生成する：

```
━━━━━━━━━━━━━━━━━━━━━━━
【シナリオ】
[企業・組織の背景説明 300〜500字程度]
[システム構成図や設定の説明]
[発生した事象または設計課題]
━━━━━━━━━━━━━━━━━━━━━━━

[設問1] [穴埋め・記述・選択]（配点：〇点）

[設問2] 〜〜について、〜〜字以内で説明せよ。（配点：〇点）

[設問3] 〜〜（配点：〇点）
```

### Step 3: 解答待ち

設問を提示したら、ユーザーの解答を待つ。時間を測りたいか確認してもよい。

### Step 4: 模範解答と採点

ユーザーが解答したら、各設問ごとに：

```
【設問X】
■ 模範解答：
[採点基準に沿った解答例]

■ 採点ポイント（キーワード）：
[必須キーワード・概念]

■ あなたの解答へのフィードバック：
[良い点・不足している点・表現の改善案]

■ 背景知識の補足：
[試験で問われる理由・関連する攻撃手法や対策]
```

## 採点の基準

- **キーワードの的確さ**：技術用語を正確に使えているか
- **因果関係の明確さ**：「〜だから〜になる」の論理が通っているか
- **字数制限の遵守**：指定字数の±10%以内か
- **具体性**：抽象的な回答より具体的な技術・手順を示せているか

## 頻出の採点キーワード例

| テーマ | 必須キーワード |
|--------|--------------|
| SQLインジェクション対策 | プレースホルダ、バインド機構、エスケープ |
| XSS対策 | サニタイズ、エスケープ、CSP、HttpOnly属性 |
| CSRF対策 | トークン、SameSite属性、Refererチェック |
| 不正アクセス対応 | ログ保全、証拠保全、隔離、CSIRT |
| TLS設定 | 前方秘匿性、PFS、HSTS、証明書ピンニング |
